# Global Temperature Analysis 🌍

## Overview

This project explores historical global temperature changes using Python and climate datasets. It aims to analyze long-term temperature trends, compare temperature variations across continents, and investigate the relationship between time and global land temperatures.

## Objectives

- Analyze historical global land temperature trends.
- Explore annual temperature variations.
- Compare average temperatures across continents.
- Study the correlation between year and global temperature.
- Apply Linear Regression to model the relationship between time and temperature.

## Dataset

The analysis uses two datasets:

- `GlobalTemperatures.csv`
- `GlobalLandTemperaturesByCountry.csv`

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Methods

1. Data loading and preprocessing.
2. Missing values handling.
3. Temporal aggregation and exploratory data analysis.
4. Geographical analysis by continent.
5. Correlation analysis.
6. Linear Regression modelling.
7. Model evaluation using R².

## Installation

Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
```

## Running the Project

```bash
python global_temperature_analysis.py
```
